## Sobre

### O Kami

O Kami é um sistema de **gerenciamento de fichas de personagens** e **rolagem de dados** para RPG, criado para ajudar jogadores e mestres de RPG a se organizarem durante as sessões. Ele permite a criação de fichas de personagens completamente personalizadas podendo ser utilizado para quase qualquer sistema de regras, além da criação de mensagens personalizadas com dados permitindo a utilização sem a necessidade de um novo comando, somente o clique de um botão é suficiente para jogar um dado.

- **Fichas:** criação e edição com controle total da arquitetura do personagem — seções e atributos com tipagem de dados (texto, número, imagem, lista, barra de progresso).
- **Rolagem:** qualquer combinação de dados (`1d20`, `3d6`, `1d10+5`), operações matemáticas e lógicas, vantagem/desvantagem e comparadores (`>`, `<`).
- **Organização:** comandos para renomear seções/atributos, excluir conteúdo e consultar um painel de `/ajuda` como manual de referência.

### Atualização (versão 5)

O BOT recebeu sua maior atualização: a **versão 5**, completamente reescrita do zero. Ele ficou muito mais **leve** (uso de memória reduzido em ~92%) e mais **estável** que a versão anterior.

- **Nenhuma ficha foi perdida** — tudo foi migrado da versão antiga para a nova.
- **Alguns comandos mudaram de nome e de funcionalidade** — recomendamos a leitura do `/ajuda`, principalmente do `/roll` e dos comandos relacionados a ficha.
- Algumas funcionalidades ainda estão em ajustes e devem ser finalizadas em breve.

### Foco no site

O projeto ganhou um novo foco: o desenvolvimento de novas funcionalidades passa a priorizar **o site**, que não depende de outra plataforma para existir. Muitas funcionalidades — principalmente relacionadas a fichas e campanhas — simplesmente não são viáveis no Discord, onde se trabalha só com comandos de texto e poucos tipos de componentes.

**Isso _não_ significa que o BOT vai parar de existir.** O BOT continua disponível e a integração entre os dois permanece nos planos, para que possam ser usados simultaneamente.
